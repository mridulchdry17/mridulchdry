# mridul.c — portfolio

Personal portfolio of **Mridul Chaudhary** — AI Engineer.

> I build agentic AI that replaces hours of manual work. Production RevOps intelligence, LLM agents, and automation pipelines — measured in hours saved, not demos.

## Stack

A single, self-contained `index.html` — inline CSS + vanilla JS. No frameworks, no build step, no external requests. Deploys anywhere static.

- **Design:** "instrument-panel minimalism" — near-black canvas, one desaturated cyan-slate accent, system fonts, bracketed mono signage, sticky indexed spine, hairline cards with viewfinder hovers, an animated agent-trace hero.
- **Interactions:** scroll-reveal, count-up stats, active-section nav, copy-to-clipboard email, animated agent graph. All gated behind `prefers-reduced-motion`.
- **A11y:** semantic landmarks, focus states, reduced-motion support, responsive down to 320px.

## Run locally

Just open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Deploy

Push to `main`. Enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root). It's a single static file — nothing to build.
